🔒 Zero-Knowledge Authentication

FlakeSecure Embeddable Iframe & Drop-In SDK

Ermöglicht es Website-Betreibern, biometrischen FlakeSecure QR-Login direkt via Iframe in ihre Seiten einzubinden. Der Server des Betreibers erhält die Daten über den normalen Login-Weg, während der FlakeSecure-Server die Zugangsdaten niemals unverschlüsselt sieht.

🌐 Beispiel-Website des Anbieters (z. B. Acme Portal)
🏢 Acme Cloud Portal
https://portal.acme-corp.com
ODER MIT BIOMETRIE
⚡ Live-Inspektor & Zero-Knowledge Protokoll

Beobachte in Echtzeit, wie der Schlüssel im Browser generiert wird, wie die verschlüsselten Daten ankommen und wie die Host-Seite die Eingabefelder ausfüllt:

[Bereit] Initialisiere FlakeSecure Embed SDK... [Init] Iframe geladen von: https://flakesecure.snowystudio.dev/embed/login [Sicherheit] 256-Bit AES-Schlüssel lokal im Iframe generiert. [Zero-Knowledge] FlakeSecure-Relay besitzt den Schlüssel NICHT. [Status] Warte auf Scan via FlakeSecure Mobile App...

Sicherheits-Garantien:

  • ✅ Ende-zu-Ende verschlüsselt: Der AES-256-CTR Schlüssel existiert nur im Browser des Nutzers.
  • ✅ FlakeSecure Relay Server: Sieht zu keinem Zeitpunkt unverschlüsselte Daten (nur Ciphertext).
  • ✅ Betreiber-Integration: Der Server des Anbieters erhält die Zugangsdaten über das gewohnte Form-POST.
  • ✅ Cross-Origin Schutz: Iframe kommuniziert sicher via postMessage mit Domain-Validierung.
💻 Integrations-Anleitung für Website-Betreiber

Füge einfach das SDK-Script vor dem schließenden </body>-Tag deiner Login-Seite ein. Es erkennt das Formular automatisch: 

<!-- FlakeSecure Drop-In SDK: Automatische Formular-Erkennung & Autofill -->
<script src="https://flakesecure.snowystudio.dev/embed.js" 
        data-auto-mount="true" 
        data-theme="dark" 
        data-auto-submit="true">
</script>

Platziere das Widget an einer beliebigen Stelle in deinem eigenen HTML-Layout: 

<!-- Platzhalter im Formular -->
<div id="flakesecure-widget"></div>

<!-- SDK laden und im Container einhängen -->
<script src="https://flakesecure.snowystudio.dev/embed.js" 
        data-container="#flakesecure-widget" 
        data-theme="dark">
</script>

Zeige einen "Mit FlakeSecure anmelden"-Button, der den QR-Code in einem eleganten Lightbox-Modal öffnet: 

<!-- Container für den Login-Button -->
<div id="fs-login-btn-box"></div>

<script src="https://flakesecure.snowystudio.dev/embed.js" 
        data-button-container="#fs-login-btn-box">
</script>

Falls du gar kein externes JavaScript auf deiner Seite einbinden möchtest, kannst du das Iframe direkt verwenden und auf postMessage lauschen: 

<!-- Direktes Iframe ohne Fremd-JS -->
<iframe src="https://flakesecure.snowystudio.dev/embed/login?domain=deine-seite.de&theme=dark" 
        width="320" height="420" 
        style="border:none; border-radius:20px; overflow:hidden;">
</iframe>

<script>
window.addEventListener('message', function (event) {
  if (event.origin !== 'https://flakesecure.snowystudio.dev') return;
  if (event.data && event.data.type === 'FLAKESECURE_LOGIN_DATA') {
    document.querySelector('input[name="username"]').value = event.data.username;
    document.querySelector('input[name="password"]').value = event.data.password;
    document.querySelector('#my-login-form').submit();
  }
});
</script>

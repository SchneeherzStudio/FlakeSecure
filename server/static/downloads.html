Browser Extension Installation Guide (Developer Mode)

  1. Download the .zip package for your browser above and unzip the archive to a local folder.
  2. In Chrome / Edge / Brave: Open chrome://extensions, activate Developer mode in the top-right corner, and click Load unpacked. Select the unzipped folder.
  3. In Firefox: Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and select the manifest.json file inside the unzipped folder.
